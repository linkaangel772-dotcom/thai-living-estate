Важно о сохранении

Изменения пока сохраняются как черновики в этом браузере. Чтобы обновить публичный сайт, нажми «Экспорт каталога», затем замени файл data/properties.json в GitHub на экспортированный JSON и подтверди Commit changes. Прямое сохранение в GitHub ещё не подключено.
